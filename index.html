Ebooks.lk — Next.js app

This project is not a PHP/XAMPP site. Apache cannot run it by itself. You must start the Node.js dev server, then open the app on port 3000.

Correct login URL:

http://localhost:3000/login

Not http://localhost/web-projects/ebooks.lk:3000/login — that mixes Apache (port 80) with a path that looks like a port. Use localhost:3000 instead.

First-time setup

  1. Install Node.js LTS from nodejs.org
  2. Open a terminal in this folder
  3. Run: npm install
  4. Copy .env.example to .env and edit secrets
  5. Run: npm run db:setup
  6. Run: npm run dev (or double-click start-dev.bat)
  7. Open http://localhost:3000/login

Demo accounts

Local dev only. Run npm run db:setup — see .env.example for SEED_DEMO_PASSWORD.
